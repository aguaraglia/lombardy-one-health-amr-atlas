# Fonti originali

Le fonti originali di grandi dimensioni devono essere conservate fuori dal
repository, nella struttura IIB_FILES equivalente a:

`IIB_FILES/05_CODE/CODE_LOM_AMR_ATLAS/lom_amr_atlas/raw/`

Ogni acquisizione deve essere registrata in `metadata/SNAPSHOTS.tsv` con URL,
data, versione, percorso locale e SHA-256.
